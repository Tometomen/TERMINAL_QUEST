## ブラウザ操作

Chromium 154.0.8037.57とソフトウェアWebGL（SwiftShader）を使用しました。`tools/browser-full.cjs` は新規コンテキストから開始し、クリックとキーボード入力で全30ミッションを通しプレイしています。

- 通常4件からボス、ボスから次レベルへの解放と画面遷移が成立する。
- ファイル操作、ログ調査、パイプ・出力、仮想権限・プロセス・容量・サービス操作を含む全ミッションを達成する。
- 最終ボスの権限・巨大ログ・暴走プロセスを修復してWebサービスを復旧する。
- 全30件クリアでXPが8400になり、ページ再読み込み後もクリア履歴・XP・全レベルの解放が復元される。
- ブラウザの実行エラーが発生しない。

入力履歴・カーソル編集・不正入力後の継続は開発中の基本操作確認でも実行しました。現在の再実行用スクリプトは下表の5本です。

### 入力・長いログ・設定

`tools/browser-input.cjs` ではヒントと図鑑を開閉してから入力を続け、16,000文字を超えるログを表示しました。ネイティブのホイール操作前後で、入力カーソルを含まないターミナル出力領域の描画ピクセルが変わることを検証しています。その後もキーボードでミッションを達成でき、ヒント使用によるBランクとXP 750を確認しました。

`tools/browser-settings.cjs` は全30件クリア状態のコピーを使い、音量・ミュート・演出軽減を変更して保存・再読み込みを確認しました。リセットのキャンセルではXP 8400が残り、確定時はクリア履歴・XP・設定が初期状態へ戻り、再読み込み後も空の記録が維持されます。720×500ではPC推奨の案内が表示されます。スピーカーからの実音は未確認です。

### 60秒タイピング

`tools/browser-typing.cjs` により、実時間で60,041ミリ秒のチャレンジを実行しました。正解5回・誤入力1回の結果は、完成5コマンド、正確率86.1111%、KPM 36、最大コンボ5でした。ミッションのXPは開始時の600のままで、ページを実際に再読み込みして自己ベストの復元も確認しました。前提となる習得済みコマンドは、新規の独立コンテキストに妥当なLEVEL 1クリア状態として用意しています。ミッションを実操作で獲得する経路は全30件のブラウザテストで確認しています。

### 保存の異常系

`tools/browser-storage.cjs` で以下を別々の新規ブラウザコンテキストで実行し、いずれも起動・ミッション操作を継続し、ブラウザ実行エラーがないことを確認しました。

- `localStorage`が利用できず、アクセス時にSecurityErrorを返す。
- 起動後の書き込みがQuotaExceededErrorで拒否され、達成記録を保存できない。
- セーブのバージョンが999という未対応値で、初期状態から開始する。その後のクリアでバージョン1の妥当な記録を保存する。

### ブラウザチェックの再実行

Web版をビルドしてHTTPサーバーを起動した状態で、別のシェルから実行します。Node.jsとPlaywrightはこの任意の操作テストだけに必要です。スクリプトはこのクラウド環境用で、状態の受け渡しに `/workspace/.cache/` を使用します。

```bash
npm install --prefix .local/browser playwright@1.56.1
mkdir -p /workspace/.cache
export NODE_PATH="$PWD/.local/browser/node_modules"
export TQ_CHROMIUM=/usr/bin/chromium
node tools/browser-full.cjs
node tools/browser-settings.cjs
node tools/browser-typing.cjs
node tools/browser-input.cjs
node tools/browser-storage.cjs
```

`TQ_CHROMIUM`をインストール済みChromiumのパスへ変更してください。配信先を変える場合は `TQ_GAME_URL` を指定できます。すべて新規の独立コンテキストを使用し、普段使うブラウザのデータには触れません。スクリーンショットを `docs/screenshots/` へ出力します。

| スクリプト | 目的・前提 |
| --- | --- |
| `node tools/browser-full.cjs` | 全30件を新規状態からプレイ。`/workspace/.cache/tq-allclear-state.json`を出力 |
| `node tools/browser-settings.cjs` | fullの保存状態のコピーで設定・リセット・小画面案内を確認。fullの後に実行 |
| `node tools/browser-typing.cjs` | LEVEL 1クリアのテスト状態から実時間の60秒と成績・再読み込み。`/workspace/.cache/tq-typing-state.json`を出力 |
| `node tools/browser-input.cjs` | typingの保存状態のコピーでヒント・図鑑後のフォーカス、長いログ、ホイールを確認。typingの後に実行 |
| `node tools/browser-storage.cjs` | 新規の独立コンテキストで、保存先なし・書き込み拒否・不正バージョンを確認 |

通常PCへ持ち出す場合はスクリプト内の状態ファイルの保存先を変更してください。通常のゲーム実行やJUnitにNode.js・Playwrightは不要です。
