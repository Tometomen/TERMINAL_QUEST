# PC／ブラウザ操作の確認手順

自動テストでは仮想エンジンと進行のロジックを確認します。このチェックリストは描画、入力、保存、画面遷移の確認用です。実際に実行した範囲は [検証記録](validation.md) に記録します。チェックボックスは確認済みの証拠ではありません。

## 起動・基本操作

- [ ] `./gradlew lwjgl3:run` でタイトルを描画できる。日本語に欠落や豆腐がない。
- [ ] `./gradlew html:dist` 後、HTTPサーバーからWeb版を開ける。ブラウザコンソールに実行エラーがない。
- [ ] 1280×800と異なるPCサイズでボタン・入力欄が画面内に収まり、小さい画面ではPC推奨を表示する。
- [ ] 「トレーニングを始める」から6レベルが見える。LEVEL 1のみ解放され、他レベルの条件が表示される。
- [ ] LEVEL 1の最初のミッションを選ぶと入力欄にフォーカスがある。`pwd` + Enterで現在地を表示し、達成する。
- [ ] 結果からレベル選択へ戻り、クリア数・XP・最高ランクを確認できる。

## 入力フォーカス・履歴

- [ ] 未クリアのミッションで `help`、`ls` 等を複数回入力し、Enterを続けて受け付ける。
- [ ] ↑／↓で履歴を移動し、入力途中の下書きへ戻れる。←／→とBackspaceが使える。
- [ ] 実行ボタンをクリックした後も続けて入力できる。
- [ ] ヒント、図鑑、設定を開閉した後に入力欄へ戻れる。「ターミナルに戻る」も機能する。
- [ ] 存在しないパス、不明コマンド、閉じていない引用符は読みやすいエラーになり、次の入力を受け付ける。
- [ ] `help` や長いログを繰り返し表示しても履歴をスクロールできる。新しい出力を確認できる。
- [ ] `cat /dev/null` の空出力、`df` の大きな数値、長いパスでも表示が破綻しない。

## 進行・学習

- [ ] 各レベルの通常4ミッションをクリアする前はボスに挑戦できない。
- [ ] 通常4ミッションをクリアするとボスが解放され、ボスクリアで次のレベルが解放される。
- [ ] 初学者には入力例があり、中級者以上は任意のヒントを3段階まで表示する。
- [ ] クリア画面に使用コマンド、エラー数、ヒント数、経過時間、ランクがある。
- [ ] 低ランクでも次へ進める。再挑戦で最高ランクは改善でき、XPは重複加算されない。
- [ ] 全30ミッションの解法が成立する。複合課題は異なる妥当な順序・手順でも達成できる。
- [ ] 最終ボスで原因が残っている間は再起動が失敗する。権限・ログ容量・暴走プロセスを修復した後に再起動すると正常稼働する。

## 保存・設定・タイピング

- [ ] ミッションをクリア後、ページを再読み込み／PC版を再起動して進捗・XP・ランクが復元される。
- [ ] 音量・ミュートを変え、効果音と再起動後の設定を確認する。
- [ ] 演出軽減を有効にして操作できる。
- [ ] セーブリセットの確認画面でキャンセルすると記録が残る。承認した場合だけ初期状態へ戻る。
- [ ] 保存禁止のブラウザ環境でもプレイが止まらず、保存失敗を確認できる。
- [ ] 60秒タイピングで正解・誤入力を行う。完成数、正確率、KPM、コンボが更新される。
- [ ] 60秒で終了して追加入力を受け付けない。自己ベストはレベル別に保存され、ミッション成績は変わらない。

## 公開前

- [ ] `html/build/dist` のみを配信して動作する。外部フォント・CDN・APIに依存していない。
- [ ] Pagesのようなサブディレクトリ配信でもゲームとアセットを読める。
- [ ] 実際の公開ワークフロー成功と公開URLでの操作は、ローカルHTTP配信の成功とは別に確認する。
